# Brief: TraceGate MVP

## The idea, as the user stated it (verbatim)
TraceGate MVP: a GitHub App / CI check that flags agent-written PRs which make tests pass without the feature working — weakened or deleted assertions, swapped UI selectors, tests that check mocked data instead of real changes, and missing evidence (DB row, telemetry event) declared in a per-flow YAML policy. Buyers: engineering teams already merging PRs from Claude Code, Devin or Cursor agents. Long-term vision: a full runtime gateway with approval gates and an evidence vault. No users, pricing or numbers yet.
