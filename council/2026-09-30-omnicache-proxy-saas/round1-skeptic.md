## Skeptic — Round 1
**Biggest single reason this fails:** The main promise ("cut Claude Code & Cursor bills 40–70%") probably isn't true for either tool. Claude Code already gets most of that saving from Anthropic's own prompt caching, and Cursor's requests never reach a localhost proxy, so there may be no measurable saving to sell.

**Risks**
1. **The saving may be zero or negative for Claude Code.** [Fact] Claude Code turns on Anthropic prompt caching automatically, with reported hit rates around 92% and roughly 81–82% cost reduction ([dev.to](https://dev.to/shilpamitra/how-claude-code-achieves-a-92-cache-hit-rate-a-deep-dive-into-prompt-caching-for-ai-agents-1hca), [mindstudio](https://www.mindstudio.ai/blog/prompt-caching-claude-code-token-savings)). Cache reads cost 0.1x the normal input price ([respan](https://www.respan.ai/articles/claude-prompt-caching)). [Fact, from the code] The proxy cannot stop Claude Code from running a tool on your machine. `compact_and_record_agent_tools` (`/home/user/13manmayarai-hash/omnicache-proxy/server/tool_replayer.py:972`) only records tool results and then rewrites older duplicate tool results inside the conversation history. [Assumption] Editing earlier messages changes the prompt prefix. That breaks Anthropic's cache, so tokens that were billed at 0.1x get billed again at 1.25x as cache writes. — severity 5
   Cheapest test (≤ 2 weeks): Run 10 identical real Claude Code tasks with the proxy and 10 without. Compare the billed `usage` fields (input, cache_read, cache_creation). If the net saving is under 10%, the headline claim is dead.
2. **Cursor support likely doesn't work at all.** [Fact] Cursor sends model calls through its own backend (api2.cursor.sh), so a localhost base URL can't be reached ([dev.to](https://dev.to/orchidfiles/why-localhost-doesnt-work-as-openai-base-url-in-cursor-and-how-to-fix-it-589e)). `omnicache run cursor .` probably intercepts nothing. — severity 4
   Cheapest test: Run Cursor through the wrapper for an afternoon. Empty proxy logs means Cursor has to be dropped from the pitch.
3. **The people it targets may not be paying per token.** [Assumption] Many heavy Claude Code and Cursor users are on flat-rate subscriptions (Claude Pro/Max, Cursor plans). A dollar saving means nothing to them, and routing subscription traffic through a proxy could run into provider terms. — severity 4
   Cheapest test: Survey or DM 30 heavy Claude Code users about how they pay (API key or subscription). If fewer than 30% pay per token, the paying market shrinks sharply.
4. **A "SaaS" contradicts the product's own selling point.** [Fact, from the brief] The pitch is "100% localhost" and "zero telemetry", and the FSL license keeps the tool free for internal use. A hosted service throws away the privacy argument. A local tool gives nothing to meter, and free alternatives exist. [Guess] Proxy and gateway products like LiteLLM, Helicone and Portkey already offer response caching; I didn't verify their current features. — severity 4
   Cheapest test: Put up a pricing page with a $10–20/month "team shared cache" tier next to the free local version, then post it where Claude Code users gather. Fewer than 20 signups from 1,000 visitors kills the SaaS angle.
5. **Stale cached output causes wrong agent actions.** [Fact, from the code] `bash` is marked cacheable, invalidated only by git or workspace state (`tool_replayer.py:48`). Test results, env-dependent commands and network state can change without any file changing. [Assumption] The first report of "the agent acted on stale output" costs a lot of trust. The project is also very broad for one builder (P2P mesh, CRDTs, audio and vision caches, Helm charts), which puts support load at risk. — severity 3
   Cheapest test: Replay 50 real sessions and count cache hits that returned output different from a fresh run. Any non-trivial rate means the default policy has to change.

**What would change my mind:** A reproducible benchmark on real Claude Code sessions showing a net reduction of 30% or more in *billed* tokens compared with native prompt caching, plus 10 users paying per token who say they'd pay for it.
